# 安溥歌词拼贴诗

一个单页面 H5 拼贴诗原型，保存在当前 `拼贴诗` 文件夹中。

## 打开方式

直接打开 `index.html` 即可使用。为了更接近手机浏览器环境，也可以在本目录启动静态服务后访问本地地址。

当前我已启动本地预览：

```bash
http://127.0.0.1:4173/
```

## 歌词数据

素材库来自 `lyric-data.js`，由 `安溥歌词.xlsx` 的前两列生成：

第一列是字条文本，第二列是歌名。若第二列为空，会继承上一行出现过的歌名。默认素材库会把全部字条随机打乱，并按每组 15-20 条展示。点击「换一组」会切换到下一组随机字条，并重置素材库里的即兴裁切。

「按歌名搜索」会按歌名筛选该歌全部字条，英文歌名不区分大小写。

## 已实现

- 歌词纸条素材库
- Excel 歌词数据导入
- 随机素材分组，每组 15-20 条
- 按歌名搜索，英文大小写不敏感
- 纸条选中染色与复古色板
- 小剪刀二次裁切
- 拖拽入画与双击掉落
- 随机轻微旋转
- PC 滚轮旋转，Shift + 滚轮缩放
- 移动端双指旋转与缩放
- 画布 3:4 比例
- 三张纸纹画布背景：横线纸、冷白、黑纸
- 本地图片上传为背景
- 选中置顶与删除
- 无控制框的 PNG 卡片导出
